# 競馬予想の記録

機械学習モデルによる中央競馬(JRA)単勝の予想を、レース前に公開して記録しているリポジトリです。

**販売も推奨も行っていません。** 検証中のモデルが実際にどう振る舞うかを、
事後に書き換えられない形で残すことだけが目的です。

## 現時点の到達点と限界

過去8年分(2019-2026年、約35万走)を対象に、各年をその年より前のデータだけで
学習し直すウォークフォワード検証を行っています。確定オッズを基準にすると、
選抜した馬の勝率は市場の見立てを一貫して上回りました。

ただし**実運用では話が変わります**。購入判断は締切前に行う必要がありますが、
JRAの単勝プールは発走6分前の時点で最終規模の42%程度しか集まっておらず、
残りの約58%が最後の6分間に流入します。この時点で見えているのは市場の半分以下です。

事前オッズを使った場合の期待回収率は、検証の結果**90〜100%程度**と見積もっています。
控除率20%を跳ね返せるかどうかの境界線上で、**利益が出る水準には達していません。**

この記録は、その見積もりが実際のレースでどうなるかを確かめるためのものです。

## ファイル

| ファイル | 内容 |
|---|---|
| `predictions_YYYYMMDD_HHMM.csv` | 対象レースの全出走馬。推定確率と期待値 |
| `picks_YYYYMMDD_HHMM.csv` | そのうち期待値上位2%(買い目) |

ファイル名の日時は生成時刻です。コミット時刻がレース発走前であることが、
事後に作成したものでないことの担保になります。

## 列の説明

| 列 | 意味 |
|---|---|
| `odds` | 生成時点の単勝オッズ(前日発売または当日の途中経過) |
| `p_mkt` | オッズから逆算した市場の暗黙勝率(レース内で合計1に正規化) |
| `p_mdl` | モデルの推定勝率(同上) |
| `ev` | 期待値 = `p_mdl` × `odds`。1.0で損益分岐 |
| `edge` | `p_mdl` ÷ `p_mkt`。市場に対する強気の度合い |

`odds` は生成時点の値です。払戻は確定オッズで決まるため、実際の結果とは差が出ます。

## 手法の概要

- **データ**: JRA-VAN Data Lab.(2015年以降)
- **モデル**: LightGBM。目的関数はレース内 softmax の交差エントロピー
  (条件付きロジット / Plackett-Luce)。初期スコアに `log(市場確率)` を置き、
  市場からの乖離だけを学習させる構成
- **特徴量**: 前走以前の走破内容(着順、レース平均との相対上がり3F、通過順、
  タイム差)、出走間隔、距離・馬場の変更、馬体重、JRA-VANのマイニング予測など
- **選抜**: 各レース群で期待値上位2%

## 運用上の約束

記録の意味を保つため、以下を守ります。

- 買い目は**必ずレース前にコミット**する
- **結果を見て設定を変えない**。上位2%という基準は固定する
- 的中・不的中にかかわらず**全件を残す**。都合の良い期間だけを切り出さない

数十点では的中ゼロも連続的中も普通に起こります。意味のある評価には
数千点規模の蓄積が必要で、それまでは短期の成績に解釈を与えません。
